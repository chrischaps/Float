# CLAUDE.md — Float

A contemplative first-person experience on the Flint engine: you sit on a
hand-lashed wooden raft, legs dangling in the water, drifting on an endless
stylized ocean as the sky wheels from sunrise to starscape.

**Design north star:** the ocean is the protagonist — wave *physics* must be
believable (Gerstner dynamics, real dispersion) even though the *look* is
graphic and cel-shaded (flat bold blues, hard-edged white foam, pastel skies).
Reference images live in `reference/water/` and `reference/raft/`.

## Layout

```
engine/       Flint engine as git subtree (remote: engine, branch main)
scenes/       *.scene.toml (float.scene.toml is the main scene)
scripts/      Rhai gameplay scripts
schemas/      Game component schemas (layered over engine/schemas)
specs/        Design notes
models/       GLBs generated by tools/*.py (do not hand-edit)
tools/        Python generators (trimesh models, numpy audio)
audio/        OGGs generated by tools/generate_audio.py
config/       input.toml
reference/    Visual reference images (water/, raft/)
```

## Build & run

```
build.bat                 # cargo build --release in engine/ (flint, flint-player)
play.bat [scene]          # run scenes/float.scene.toml (default)
render.bat                # headless PNG snapshots into snapshots/
python tools/generate_raft.py   # regenerate models/raft.glb
```

Schemas are layered: `--schemas engine\schemas --schemas schemas` (game wins).

## Engine subtree workflow

Engine changes are made HERE (in `engine/`), tested against Float, then pushed
upstream: `git subtree push --prefix=engine engine main` (use a `feature/*`
branch + PR if diverged — Flint's primary branch is `main`, not `master`).
Pull updates: `git subtree pull --prefix=engine engine main --squash`.

## Float-specific engine features (live in the subtree, upstreamable)

- `flint-core/src/ocean.rs` — Gerstner spectrum + CPU sampler. SINGLE SOURCE
  OF TRUTH for wave math: the GPU only sums the wave array uploaded from here.
  Any change to wave math must keep CPU/GPU parity (unit test + in-world buoy
  probe pinned to `ocean_height()`).
- `flint-render` ocean pipeline (`ocean_pipeline.rs`, `ocean_shader.wgsl`) —
  camera-snapped grid, vertex Gerstner displacement, cel-banded fragment with
  Jacobian foam. Ocean writes depth so composite fog applies.
- Sky pipeline (`sky_pipeline.rs`, `sky_shader.wgsl`) — procedural gradient,
  sun disc from `directional_lights[0]`, hash stars, FBM clouds; driven by the
  `sky` component. Time-of-day is GAME-side (`scripts/time_of_day.rhai`
  keyframe interpolation writing set_field) — do not bake TOD into the engine.
- Rhai APIs: `ocean_height(x,z)`, `ocean_normal(x,z)`, `set_cursor_captured`.

## Gotchas

- `flint render` does NOT run scripts — time-of-day snapshots need baked
  `scenes/snap_*.scene.toml` variants.
- Mouse look requires cursor capture; without a character-controller player
  entity the engine never captures — Float uses the `set_cursor_captured(true)`
  script API from `seat_camera.rhai` (added in M2).
- Wave phase is precomputed per frame in f64 and uploaded — never accumulate
  phase in f32 in the shader.
- The raft is a plain transform-driven entity (no Rapier body needed); its
  buoyancy is `scripts/raft.rhai` sampling `ocean_height` at 5 points.

## Debug controls in play

F3 toggles both panels: **Ocean Debug** (waves, colors, foam, water
clarity/turbidity, grid) and **Time of Day** (0-24h scrub slider, natural
advance toggle, day length, sun path tilt). Edits apply live through the
world's components; "Commit to File" writes them back into the scene TOML.
Escape releases the mouse (for panel use); click recaptures.
